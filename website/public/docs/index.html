Getting started, usage, and deployment for Boardchestrator.

Boardchestrator is a self-hosted agent workspace. One Go binary, one SQLite file. It brings together a kanban board, autonomous agents, a versioned wiki, and MCP tool integration behind a real-time web UI.

  • Getting started — install, configure, and run it.
