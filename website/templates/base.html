What it does

Built for agent-heavy teams

Board

Visual task management with real-time updates, swimlanes, WIP limits, and drag-and-drop — live via SSE.

Agents

Autonomous agents with tool-use, multi-step execution, and a chat interface that streams results live.

Wiki

A versioned project knowledge base with autolinking and semantic search across every note.

MCP

Universal tool integration via the Model Context Protocol — plug any tool server into the agent runtime.

Self-host it

One Go binary, one SQLite file. Run it in Docker, wire up GitHub or Google login, and let agents take over your workflow.
