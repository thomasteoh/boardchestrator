Boardchestrator is a self-hosted agent workspace. One Go binary, one SQLite file. It brings together a **kanban board**, **autonomous agents**, a **versioned wiki**, and **MCP tool integration** behind a real-time web UI.

- [Getting started](/getting-started/) — install, configure, and run it.
- [Deployment](/deployment/) — Docker, environment reference, and operations.
- [Sign-in and identity](/sign-in/) — identity providers, organisation SSO, SCIM and passkeys.
- [Concepts](/concepts/) — boards, agents, wiki, and how they fit together.
