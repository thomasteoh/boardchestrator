# Wiki

The wiki is a versioned project knowledge base. Write down decisions, onboarding notes, and operational runbooks; the wiki autolinks across the project and surfaces relevant context with semantic search.

## Writing

- Open **Wiki** from the org sidebar, then **Edit** any page.
- Pages are markdown. They support tables, code blocks, and diagrams.
- Every change is **versioned** — open **History** on a page to see what changed and when, and to revert.

## Linking

Mention another page by name and it autolinks. Reference a task with its `KEY-n` id and it becomes a task link, so notes stay connected to the work.

## Search

Semantic search across every note surfaces the pages most relevant to what you're working on, instead of just keyword matches.
