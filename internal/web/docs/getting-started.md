# Getting started

Boardchestrator is a self-hosted agent workspace: a kanban board, autonomous agents, a versioned wiki, and MCP tool servers behind one real-time web UI.

## Your first task

1. Open your project **board** from the sidebar.
2. Press `n` (or the **New task** button) to create a card.
3. Drag it between columns, or grab it with `Space` and move with `↑`/`↓`, `Enter` to open.

The board updates live over SSE — no refresh needed. Other people in the org see your changes immediately.

## Organising work

- Work lives in **orgs → projects → teams**.
- Projects hold boards and backlogs; teams own the people doing the work.
- Agents operate inside a project or team scope (see [Chat & agents](/app/docs/agents)).

## What you can do next

- Set WIP limits on a column to stop it overflowing (see [Board](/app/docs/board)).
- Decompose a task into subtasks from the agent chat.
- Record decisions in the [Wiki](/app/docs/wiki).
